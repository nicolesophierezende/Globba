# Globba

*Il tuo mondo, dietro l’angolo* – a map of international grocery stores in Turin, with product search.

| Folder / file | What it is |
|---|---|
| [`globba-app/`](globba-app/) | **The website / app.** All the code. Setup guide: [`globba-app/README.md`](globba-app/README.md). |
| [`Globba.md`](Globba.md) | The project plan. |
| [`prototype/index.html`](prototype/index.html) | The original one-file prototype. |
| [`CLAUDE.md`](CLAUDE.md) | Project brief for AI tools. |
| `netlify.toml` | Hosting settings (Netlify builds the `globba-app` folder). |

Quick start (needs Node.js 20 or newer):

```bash
cd globba-app
npm install
npm run dev
```

Then open http://localhost:4321.
